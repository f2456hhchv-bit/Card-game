# DR-002 — Palette extension: vitality.green and shield.blue

**Reason:** AF-004's colour-family semantics (Green = healing, Blue = shield) vs locked AF-002 token assignments (healing = crystal.teal, shield = plasma.cyan).
**Alternatives considered:** family reconciliation (teal counts as green, cyan as blue) — initially applied, flagged to owner.
**Chosen solution:** Project Owner ruled to extend the palette: `vitality.green #4DE868` (healing), `shield.blue #4D7CFF` (shields); roles moved off crystal.teal / plasma.cyan. Shape-pairing cues retained.
**Trade-offs:** two more tokens to maintain across accessibility remaps; cleaner semantics and later reused by the rarity ladder (Improved, Rare).
**Dependencies:** AF-002 §3, AF-004 §3, AF-007 §4, AF-008 registry.
**Future review:** none scheduled — settled canon.
**Status:** Owner ruling 2026-07-05; recorded in `docs/VISUAL_LANGUAGE.md` §3.
