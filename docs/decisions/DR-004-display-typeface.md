# DR-004 — Secondary display typeface permitted (titles only)

**Reason:** AF-009 introduced a secondary display font; locked AF-002 §9 mandated one sans family and banned decorative fonts.
**Alternatives considered:** refusing the display face and using weight variants of the primary only.
**Chosen solution:** AF-009 (owner-issued) authorised the amendment, constrained: the display face must remain a modern sans in character (distinct weight/width, not decorative), Display Title level and brand lockups only, never body text. Decorative fonts remain banned.
**Trade-offs:** one more font asset to subset/load; stronger brand presence at the top of the hierarchy.
**Dependencies:** AF-002 §9 (amended), AF-009 §1–2; concrete family selection owed by the UI implementation module.
**Future review:** at UI implementation module (family selection + licensing).
**Status:** Owner authority via AF-009, 2026-07-05.
