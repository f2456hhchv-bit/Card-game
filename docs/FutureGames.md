## Fantasy ARPG (Diablo / PoE / D&D / RuneScape / WarCraft vibe)

**Pitch:** a fantasy-themed action RPG built on the same premium, offline,
no-microtransactions principles as AFTERLIGHT — but with the depth and identity
of the classic loot-ARPG genre rather than a space survivor.

**Core pillars the user asked for:**
- **Hero classes with distinct traits:** wizard, warlock, barbarian,
  necromancer, druid — plus playable ancestries (orc, elf, human). Each should
  feel mechanically different, not just a stat tilt: unique active skills and
  playstyles.
- **Diablo-style proc / affix rolls:** every weapon and armour piece rolls
  differently, so no two drops feel the same. Prefixes/suffixes, tiers, implicit
  vs. explicit mods, rare/unique items.
- **A huge volume of skills:** deep, buildable skill trees / active + passive
  abilities — the "immense skill volume" the user is excited about.

**What already transfers from AFTERLIGHT (theme-agnostic systems):**
- Gear inventory + rarity tiers + affixes + set bonuses + salvage/reroll (Alloy)
- Meta-progression, achievements, multiple game modes, records
- The original-SVG production-art pipeline (`ArtManifest` + `blitKey` seam)
- Fixed-timestep sim / render split, spawn director, boss controller

**What's genuinely new:** fantasy hero *classes* with real active skills (vs.
auto-firing weapons), a skill system/tree, item types (weapon/armour/ring/
amulet), and fantasy enemy/biome/boss art.

**Status:** parked by the user ("this will be another game we tackle"). Revisit
when explicitly asked.
