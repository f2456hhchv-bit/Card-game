# The Evolution Engine (AF-139)

Built entirely under `src/game/evolutionEngine/`, composing with an unusually wide slice of the locked stack rather than duplicating any of it. A dedicated research pass preceded design (the same research-first pattern used for AF-132/133/138) and found that most of this spec's 11 pillars have no real backing anywhere — safe new territory — while its "Great Projects" section collides directly with two already-locked rosters.

## What's new

- **`evolutionEngineData.ts`** — `EVOLUTION_PILLARS` (11, flavour classification). `EQUIPMENT_EVOLUTION_STAGES` (6: Prototype → Historic Masterpiece) is a new craftsmanship axis, deliberately never touching AF-007's locked `RARITY_LADDER` (rarity is drop-luck; this is earned refinement). `ARCHITECTURAL_EVOLUTION_STAGES` (6) is a pure mapping (`architecturalStageFor`) over AF-090's real, locked 7-stage `SettlementDevelopmentStage` — never a competing, independently-tracked value. `PLAYER_EVOLUTION_RANKS` (6: Rookie → Legend, via `playerEvolutionRankFor`) derives purely from AF-026's real `MetaProgression.snapshot.accountLevel`, since AF-133/136's `reputationTitleFor` is flavour text keyed by legacy category, not a rank sequence. `TRANSPORT_EVOLUTION_TIERS` (6, via `transportTierFor`) gates its top two tiers behind AF-024's real `warp-charting`/`GALAXY_FAST_TRAVEL` research unlock. `commanderMaturityScore`/`commanderMaturityStageFor` compose AF-071's real talents/mission-beat state and AF-130's real bond level into one 0-100 maturity stage. `technologyEraFor` composes AF-024's real unlocked-node count/tier average into a galaxy-wide era. Many flavour-only category lists (Technology/Cultural/Language/Research/AI/Planetary/Colony/Historical Evolution examples, Accessibility surfaces) stay as typed data, matching AF-137's precedent of not building a dedicated class per flavour category.
- **Great Projects naming-collision note** — the research pass found this spec's 7 example Great Projects are near-duplicates of AF-090's real `MEGASTRUCTURES` or AF-138's real `CIVILISATION_MEGAPROJECTS` ("Dyson Swarm" ≈ `dyson-array-lucent`; "Galactic University" ≈ `megaproject-interstellar-university`; "Deep Space Observatory Ring" ≈ `megaproject-deep-space-telescope`; "Atlas Gateway Network" ≈ `quantum-gate-axiom`). Rather than build a third near-duplicate roster, `GREAT_PROJECT_LINEAGE` documents which real project each example maps onto (only "Interstellar Seed Vault" is left deferred — no real match, and inventing a new megaproject entry is AF-090/AF-138's domain, not this one's), and `greatProjectsProgressSummary` reports one unified progress lens across both real rosters.
- **`EquipmentEvolutionTracker`**, **`HistoricalArchitectureLedger`** (append-only, preserving every distinct architecture layer a settlement has passed through — "cities tell their own history"), **`SpeciesAdaptationRegistry`** (real per-species adaptation history, since AF-132's `EnvironmentalRuntime` only tracks one aggregate wildlife number per system), **`CompanionEvolutionTracker`** (growth/behaviours/traits keyed by AF-131's real `CompanionHabitatEntry.id`, since that registry is pure dedup), **`LanguageEvolutionLog`** (reuses AF-135's real `EvolvingEntry` directly rather than a second versioning primitive).
- **Debug overlay** — `DebugSnapshot` gains a new `evolutionEngine` field, the same established per-module extension pattern used since AF-039.
