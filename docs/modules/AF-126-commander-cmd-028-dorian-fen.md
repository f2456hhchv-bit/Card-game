## Foundation / AF-000–125 / GP-FINAL alignment review

**Owner-authorised name substitution:** the verbatim prompt above specifies Full Name "Orion Vale," which collides with the already-locked CMD-007 "Orion Vale 'The Voidrunner'" (AF-105) — an entirely different, unrelated character (void expedition specialist vs. this module's xenobiologist/wildlife handler). Flagged to the Project Owner before implementation; the Owner chose to rename this module's commander rather than implement a duplicate full name. CMD-028 is therefore canonically implemented as **Dorian Fen** — codename, biography, personality, abilities, talent tree, relationships, dialogue, and every other spec field are otherwise realised exactly as written above, with "Orion"/"Vale" pronoun and name references in generated (non-verbatim) prose replaced by "Dorian"/"Fen." This is the only deviation from the verbatim prompt in this module.
