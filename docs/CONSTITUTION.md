# AFTERLIGHT MASTER CONSTITUTION v1.0

## SUPREME DESIGN AUTHORITY

This document is the highest governing specification for the Afterlight project.

It overrides every future implementation prompt unless explicitly revised by the Project Owner.

All AF modules extend this Constitution.

None may contradict it.

This document should always be the first specification loaded before any implementation work begins.

---

# PROJECT IDENTITY

Afterlight is a premium top-down 360° space roguelite survivor built around meaningful decisions, deep progression, endless replayability and exceptional presentation.

It is not simply about surviving.

It is about rebuilding civilisation.

The player slowly transforms a dying galaxy into one filled with hope again.

Everything should reinforce that fantasy.

---

# DESIGN MISSION

Create one of the highest-quality space roguelites ever made.

Every feature should feel handcrafted.

Every mechanic should connect to another mechanic.

Every run should create memorable stories.

Every decision should matter.

Every system should reward mastery.

Nothing should exist purely to increase feature count.

Quality always outweighs quantity.

---

# PLAYER PROMISE

Players will always receive:

- Fair challenge
- Respect for their time
- Meaningful progression
- Endless experimentation
- Exceptional build diversity
- Premium presentation
- High performance
- Accessibility
- Complete offline gameplay
- Optional online enhancements

Players should never feel manipulated.

Players should never feel forced.

Players should always feel respected.

---

# GAMEPLAY PHILOSOPHY

Gameplay always comes first.

Readability always comes before realism.

Player agency always comes before spectacle.

Every mechanic must answer one question:

"What interesting decision does this create?"

If no meaningful decision exists,

remove or redesign the mechanic.

---

# DESIGN DECISION MATRIX

Every new feature must answer:

Is it fun?

Is it readable?

Does it improve gameplay?

Does it improve replayability?

Does it respect player time?

Does it fit the universe?

Does it integrate naturally?

Does it remain performant?

Can it scale indefinitely?

Would players miss it if removed?

If any answer is "No"

Redesign.
