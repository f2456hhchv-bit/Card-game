# xeno — Bio-Engineered Xenomorph Enemy Faction (AF-051, game layer, inside `enemies/`)

**Purpose:** The sixth enemy faction, and the first whose core meter only ever grows. Where Outlaw scatter times out, Machine services degrade, the Crystal Ecosystem weakens with a dying count, Void corruption decays, and Ancient alert de-escalates (its ceiling even shrinking), the Hive's Biomass has no way down at all — "the Hive never wastes biomass, every death strengthens future generations" is literal, so even the Hive's own losses feed it. Evolution Stage is a pure ratchet over that pool. The one thing that CAN be lost tactically is the Hive Node's network link — reusing AF-047's discrete on/off flag technique — which cuts shared Healing/Target Information/Aggression to whatever survives the current encounter without ever touching Biomass itself.

**Responsibilities:** Unit/combat-style/special-mechanic/network-trait/terrain-kind/mini-boss/elite-gain vocabulary, six full sandbox `EnemyDef`s with real AF-032 `WeaponDef` ranged attacks, visual-language record, and evolution/acid-pool tuning (`xenoData`); the monotonic Biomass pool (hard-capped for fairness), the network-link flag, Rapid Reinforcement's cadence-gated call-in, and the stage-stepped, link-gated Hive Network bonuses (`HiveEvolution`).

**Dependencies:** `enemies/enemyData` (`EnemyDef` — unchanged; every def uses the `swarm` family, registered since AF-033 and unused until now). `bosses/BossArena` (`HazardZoneDef`/`stepHazardZone`/`isInsideHazard` — Acid Pools' exact engine, a fourth reuse after AF-046's mines, AF-048's Crystal Growth, and AF-049's Corruption Zones). A Living Titan IS an AF-034 Elite via the unchanged spawn path. **Deliberately does not reuse AF-039's faction-profile system** — like AF-049's Void Swarm, the Hive's own spec states it is "not an alien civilisation," so it gets no `FactionDef`; its Codex entry cross-references the Void Swarm's as the galaxy's other non-civilisation threat.

**Data structures:** `HiveEvolutionRuntime`, `HiveSnapshot`, `HIVE_EVOLUTION_TUNING`, `EVOLUTION_STAGE_THRESHOLDS`, `ACID_POOL_TUNING`.

**Extension points:** new organisms are `EnemyDef` data (eight of fourteen registered kinds await defs); new hive compositions are id lists; mini-boss kinds bind to AF-035 `BossDef` content when authored; further Hive Network traits (`HIVE_NETWORK_TRAITS`) and Biological Terrain kinds (`BIOLOGICAL_TERRAIN_KINDS`) attach to the same stage-ratio/hazard-engine surfaces.

**Known limitations:** of the ten Special Mechanics, Burrowing and Wall Traversal are mechanically live as real movement behaviours (Hive Drone and Stalker respectively), and Acid Blood is live via the Spitter/Living Titan's `poison` statusOnHit and Acid Pools; Nest Construction, Egg Clusters, Parasitic Infection, Biomass Harvesting (as its own system beyond the Evolution meter), Rapid Evolution (as a mutation-tree system beyond the stage ratchet), and Adaptive Mutation are registered awaiting content. Of the six Hive Network traits, three are mechanically live — Healing, Target Information, and Aggression — all gated on the Node's network link and stepped by the permanent Evolution Stage; Biomass (as a shared trait beyond the pool itself), Mutation Progress, and Reinforcement Calls (as a distinct trait from the Rapid Reinforcement mechanic, which IS live) are registered. AF-021's dormant `poison` `StatusKind` and AF-033's dormant `burrow`/`wallCrawling` movement behaviours all gain their first producers here. A dev-only spawn key ("4", DEV-guarded beside the debug overlay, alongside the Outlaws' "8", Machines' "9", Crystals' "7", Void's "6", and Ancient Custodians' "5") makes hive encounters deterministically verifiable in the browser.
