# ancient — Ancient Custodian Enemy Faction (AF-050, game layer, inside `enemies/`)

**Purpose:** The fifth enemy faction, and the first to get STRONGER while its units live rather than weaker as they die. Where Outlaw squads SCATTER (binary), Machine networks DEGRADE (discrete steps), the Crystal Ecosystem WEAKENS (continuous, from a count), and the Void Swarm CORRUPTS (climbs and decays with time), the Ancient Custodians ESCALATE: a five-stage security ladder — Minor Trespass, Warning, Containment, Guardian Deployment, Maximum Response — that climbs while the player trespasses near a defended site and continuously de-escalates the moment they leave, permanently capped lower every time a network node (a Shield Architect) is destroyed.

**Responsibilities:** Unit/combat-style/special-mechanic/network-trait/mini-boss/elite-gain vocabulary, six full sandbox `EnemyDef`s with real AF-032 `WeaponDef` ranged attacks, visual-language record, and security/tuning (`ancientData`); the five-stage escalation ladder (hard-capped by node count), Guardian Deployment's cadence-gated reinforcement, and the discrete stage-stepped Ancient Network bonuses (`AncientSecurity`).

**Dependencies:** `enemies/enemyData` (`EnemyDef` — unchanged; every def uses the `ancientGuardian` family, previously carrying only AF-048's single Crystal Titan). An Ancient Executor IS an AF-034 Elite via the unchanged spawn path. **Pays off AF-039's registered-but-unprofiled `ancientCustodians` FactionId** — the same content debt AF-046 paid off for the Mercenary Guild — with a full `FactionDef` profile (territory `ancientCore`, unique resource `ancientComponents`) and one additive `codex-ancient-security-doctrine` Codex entry (a pre-existing, older entry — `codex-ancient-custodians`, from Ancient Vault discovery — already covered who they are; this one covers how they fight), unlike AF-047/048/049 which each inherited an already-profiled faction.

**Data structures:** `AncientSecurityRuntime`, `SecuritySnapshot`, `ANCIENT_SECURITY_TUNING`, `SECURITY_STAGE_THRESHOLDS`.

**Extension points:** new units are `EnemyDef` data (seven of thirteen registered kinds await defs); new site compositions are id lists; mini-boss kinds bind to AF-035 `BossDef` content when authored; further Ancient Network traits (`ANCIENT_NETWORK_TRAITS`) attach to the same stage-ratio surface.

**Known limitations:** of the ten Special Mechanics, none are separately implemented as their own systems yet — Guardian Deployment (stage 3+) is mechanically live as a cadence-gated reinforcement reusing AF-047's Drone Factory pattern, and the remaining nine (Light Bridges, Energy Walls, Ancient Glyphs, Rotating Defences, Adaptive Barriers, Security Fields, Defence Arrays, Energy Mirrors, Vault Locks) are registered awaiting content. Of the six Ancient Network traits, three are mechanically live — Repair Functions (healing), Target Information (damage bonus), and Shield Capacity (incoming-damage reduction), all stepped discretely by stage rather than scaled continuously; Energy, Threat Assessment, and Security Protocols are registered. AF-021's dormant `armourBreak` `StatusKind` gets its first producer via the Defence Drone's Precision Lance and the Ancient Executor's Judgment Beam. A dev-only spawn key ("5", DEV-guarded beside the debug overlay, alongside the Outlaws' "8", Machines' "9", Crystals' "7", and Void's "6") makes site encounters deterministically verifiable in the browser.
