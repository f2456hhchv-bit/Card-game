# machines — Machine Collective Enemy Faction (AF-047, game layer, inside `enemies/`)

**Purpose:** The second enemy faction — precision, efficiency, coordination. The deliberate mirror-opposite of AF-046's Outlaws: where a broken squad *scatters* (fear), a broken network *degrades* (logic) — machines keep fighting, but Target Synchronisation, Shared Shields, Self Repair, and the Drone Factory all stop the moment the Command Core dies.

**Responsibilities:** Unit/combat-style/special-mechanic/adaptive-AI-input/network-command/mini-boss/elite-gain vocabulary, six full sandbox `EnemyDef`s with real AF-032 `WeaponDef` ranged attacks, visual-language record, and network/adaptation tuning (`machineData`); network state (linked → degraded → eliminated), per-service gating, the Drone Factory cadence, and hard-capped Adaptive AI damage-school analysis (`MachineNetwork`).

**Dependencies:** `enemies/enemyData` (`EnemyDef` — unchanged), `combat/combatTuning` (`DamageSchool` — the Adaptive AI's live analysis input). Networks reuse AF-046's pure `OutlawSquadRuntime.formationOffsets` for spawn placement (cross-module reuse, not reimplementation); machine `formation`-behaviour units anchor on the Command Core through the same AF-033 formation context AF-046 first activated. Command Cores ARE AF-034 Elites via the unchanged spawn path. The faction is AF-039's *already-profiled* Machine Collective (which has manufactured enemy weapons since AF-033's flak-orbiter) — zero new lore. Network elimination banks Research Data through AF-024's existing points path; the doctrine Codex entry (AF-043) unlocks on the first core kill.

**Data structures:** `MachineNetworkRuntime`, `NetworkSnapshot`, `MACHINE_NETWORK_TUNING`, `MACHINE_ADAPTATION_TUNING`.

**Extension points:** new units are `EnemyDef` data (eight of fourteen registered kinds await defs); new network compositions are id lists; mini-boss kinds bind to AF-035 `BossDef` content when authored; further Adaptive AI inputs (`ADAPTIVE_AI_INPUTS`) attach to the same `recordIncomingDamage`-style analysis surface.

**Known limitations:** of the eight Special Mechanics, Shared Shields, Self Repair, Drone Factories, Target Synchronisation, and (via the shield generator's `deployShields`) Defensive Networks are mechanically live; Distributed Processing, Energy Relay, and Adaptive Armour are registered awaiting content (Adaptive Armour additionally has AF-034's registered-but-dormant mutation as its natural future home). Of the seven Adaptive AI inputs, `damageTypes` is live (per-school hit analysis, hard-capped at 25% reduction — "adapts without becoming unfair" is a number, not a promise); the other six are registered. Calculated Retreats are live for the Elite Command Core via AF-034's existing elite retreat logic and for the withdrawing Constructor; rank-and-file machines fight to destruction by design — the network's Resource Preservation is its repair/factory economics, not self-preservation. Two tunings came out of the live self-review loop: the factory interval dropped 7000→4000ms (the Constructor was reliably focused down before its first build mattered), and the Constructor's movement changed kiting→retreat (a factory that chases into auto-fire range self-selects as the primary target). Dev-only spawn keys (8/9, DEV-guarded beside the debug overlay) make both factions' encounters deterministically verifiable in the browser.
