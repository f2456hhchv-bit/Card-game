# eclipsed — The Eclipsed Enemy Faction (AF-055, game layer, inside `enemies/`)

**Purpose:** The tenth enemy faction — and the first that is a mirror, not a force. It is new in two independent ways. First, corruption is a PERSONAL timeline: every member walks its own five-stage fall (Recently Lost → Corrupted → Broken → Consumed → Irrecoverable), staggered at spawn, slowed while the Memory Warden lives, and jumped forward by grief every time an ally dies — per-entity like AF-054's graph bonuses, but driven by each member's own history rather than its position in a pattern, and it never walks backward. Second, Ability Mimicry is the first mechanic whose strength reads what the player has BECOME: the composition root feeds in the player's progression level and the mirror scales with it, hard-capped for fairness. (AF-050's Ancient Custodians read only where the player *is*; the Eclipsed read what they *are* — "they represent what the player could eventually become" is a number, not just lore.)

**Responsibilities:** Unit/combat-style/special-mechanic/corruption-stage/memory-echo/mini-boss/elite-gain vocabulary, six full sandbox `EnemyDef`s with real AF-032 `WeaponDef` ranged attacks, the deterministic Memory Echo line set, visual-language record, and corruption/mimicry/echo tuning (`eclipsedData`); the per-member staggered corruption clocks, the Warden's slow, the grief jump, the capped player-mimicry, and the cadence-gated one-shot echo feed (`EclipsedCorruption`).

**Dependencies:** `enemies/enemyData` (`EnemyDef` — unchanged). An Eclipsed Champion IS an AF-034 Elite via the unchanged spawn path. Memory Echoes reuse AF-053's one-shot consume-event shape as world-building text. **Deliberately does not reuse AF-039's faction-profile system** — the Eclipsed are former humans, not a civilisation and not a polity; the fifth faction to skip a `FactionDef`, but for the opposite, sadder reason to AF-049/051/053/054's cosmic threats. Their Codex entry cross-references the Human Alliance they fell from, not another threat.

**Data structures:** `EclipsedCorruptionRuntime`, `EclipsedSnapshot`, `EclipsedMemberSnapshot`, `ECLIPSED_CORRUPTION_TUNING`, `ECLIPSED_ECHO_LINES`.

**Extension points:** new fallen are `EnemyDef` data (seven of thirteen registered kinds await defs); new group compositions are id lists; mini-boss kinds bind to AF-035 `BossDef` content when authored; new echo lines are additive entries in `ECLIPSED_ECHO_LINES`; further Special Mechanics attach to the per-member clock/stage surface.

**Known limitations:** of the ten Special Mechanics, Memory Echoes, Ability Mimicry, Unstable Warp Jumps (the Broken Pilot's `teleport` ability — the kind's first base-def producer; until now only AF-034's elite tiers carried it), and Identity Collapse (the Champion's low-health enrage) are mechanically live; Corruption Bursts, Broken Shield Cycles, Ghost Images, Ship Malfunctions, Corrupted Equipment, and Memory Fragments are registered awaiting content. Corruption stages currently step behaviour through the shared damage/speed bonuses; per-stage visual evolution binds at the AF-002/006 asset pass. The Lost Scout gives AF-033's dormant `ambush` movement behaviour its first base-def producer. The Memory Warden's death is a deliberate moral-tactical choice: the survivors slip faster without it, so killing the healer-analogue first — the reflex every prior faction taught — costs something here. A dev-only spawn key ("0", DEV-guarded beside the debug overlay, completing the 0–9 row alongside 8/9/7/6/5/4/3/2/1) makes Eclipsed encounters deterministically verifiable in the browser.
