# enemies — Enemy Framework (AF-033) + Elite Enemy Framework (AF-034, game layer)

**Purpose:** Instantly recognisable obstacles whose interaction — not health inflation — produces difficulty. Every enemy carries identity, counterplay, and a readable telegraph. Elites (AF-034) are generated, unique battlefield events built on top of the same enemy engine, not a parallel system.

**Responsibilities:** Data shapes for family/role/movement/attack/special-ability/elite/death-events (`enemyData`), deterministic per-behaviour motion (`EnemyMovement`), AI state transitions (`EnemyAI`, a table over AF-016's existing `StateMachine`), per-instance telegraph/cooldown gating and condition-gated special-ability bonus (`EnemyRuntime`), death-event configuration lookup (`DeathEvents`), and the no-overlap fingerprint check (`findEnemyOverlap`). AF-034 adds: the seven-tier/fifteen-mutation vocabulary (`eliteData`) and the deterministic Base→Tier→Mutations→Stat/Behaviour/Reward Package→Identity generation pipeline (`EliteGenerator`).

**Dependencies:** `game/weapons` (`WeaponDef` — a ranged enemy attack IS a weapon, fired through the exact same engine the player uses). `game/combat` (`DamageSchool`/`StackingRule` for melee attacks and mutation stacking; `StatusEngine` for status-on-hit and Status Explosion death events — reused, not duplicated). `game/equipment` (`PassiveTrigger`, `EquipmentBonus` — an enemy's special-ability trigger/effect is the identical shape a Commander's or Ship's passive uses). `game/relics` (`RELIC_RARITIES` — Elite Tiers reuse AF-029's exact 7-tier restricted rarity view for reward floors, the same pattern AF-029 itself drew from AF-023). `core/state` (`StateMachine` — the AI state chain is a transition table over the existing generic class).

**Data structures:** `EnemyDef`, `EnemyAttack`/`AttackMechanism` (melee or a wrapped `WeaponDef`), `EnemySpecialAbility`, `EliteModifier`, `EnemyRuntimeSnapshot` (AF-033); `EliteTierDef`, `MutationDef`, `MutationEffects` (elite-only numerics layered alongside `EnemyDef`, never merged into it), `EliteInstance` (AF-034).

**Extension points:** new enemies are data, checked against `findEnemyOverlap` before shipping; new families/roles extend their unions; Group Behaviour and most Special Abilities are schema-complete but await their consuming systems, the "registered, no consumer yet" pattern AF-028 used for `droneEffectiveness`/`orbitalPower`. Nine of fifteen Elite mutations are mechanically live (`MUTATION_DEFS[kind].mechanicallyLive`); the rest (Reflective Armour, Gravity Field, Summoner, Quantum Shift, Temporal Echo, Adaptive Armour) are schema-complete and await their own mechanic.

**Known limitations:** enemy/Elite card, silhouette, telegraph, and Codex UI build from AF-002/AF-004/AF-007/AF-008/AF-005 at the content/visual/UI module; target selection has exactly one real candidate (the player) until allies/objectives exist, so it degenerates to an engagement gate rather than a true choice among candidates; Elite AI's Ability Timing/Environmental Awareness/Support Coordination bind once abilities and allied enemies exist to coordinate with — only Retreat Logic is mechanically live today.
