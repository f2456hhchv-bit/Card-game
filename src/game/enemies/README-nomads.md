# nomads — Stellar Nomad Enemy Faction (AF-052, game layer, inside `enemies/`)

**Purpose:** The seventh enemy faction, and the first driven by an actively-spent economy rather than a passive multiplier. Every prior faction computes a bonus continuously from a single state (a scatter timer, per-service flags, a living count, a decaying level, an escalating stage, a monotonic ratchet). The Nomads instead earn Scrap passively (Salvage Recovery) and spend it on discrete tactical actions — Deployable Turrets, Scrap Shields, Emergency Repairs — each gated on BOTH affordability and its own cooldown. Destroying the Command Ship doesn't scatter, degrade, weaken, corrupt, de-escalate, or sever anything that already exists — it throttles the fleet's *future* income rate ("disrupts fleet cohesion"), a fresh mechanical shape none of the six prior factions used.

**Responsibilities:** Unit/combat-style/special-mechanic/fleet-coordination/mini-boss/elite-gain vocabulary, six full sandbox `EnemyDef`s with real AF-032 `WeaponDef` ranged attacks, visual-language record, and fleet tuning (`nomadData`); the Scrap economy (earned passively, spent on three cost-and-cooldown-gated actions), the Command Ship's income-throttle-on-death, and the fully independent, headcount-only Escort Protection trait (`NomadFleet`).

**Dependencies:** `enemies/enemyData` (`EnemyDef` — unchanged). A Nomad Flagship IS an AF-034 Elite via the unchanged spawn path — and it also functions as the fleet's Command Ship, unlike every prior faction's separate support-unit "node". **Pays off AF-039's registered-but-unprofiled `nomadFleet` FactionId** — the same content debt AF-046 paid off for the Mercenary Guild and AF-050 for the Ancient Custodians — with a full `FactionDef` profile (territory `darkNebula`, resource `commonMaterials`) and one additive `codex-nomad-fleet` faction Codex entry.

**Data structures:** `NomadFleetRuntime`, `FleetSnapshot`, `NOMAD_FLEET_TUNING`.

**Extension points:** new crew are `EnemyDef` data (eight of fourteen registered kinds await defs); new fleet compositions are id lists; mini-boss kinds bind to AF-035 `BossDef` content when authored; further Fleet Coordination actions (`FLEET_COORDINATION_ACTIONS`) attach to the same Scrap-economy/headcount surfaces.

**Known limitations:** of the ten Special Mechanics, Deployable Turrets, Scrap Shields, and Repair Fields (Emergency Repairs) are mechanically live as Scrap-gated actions; Salvage Recovery is live as the passive income source itself; Magnetic Harpoons is live via the Hunter's Harpoon Cannon (`stasis` status + `returning` projectile); Cargo Drops, Drone Repair, Emergency Escape (beyond the Flagship's own `cloak` ability), EMP Nets, and Improvised Minefields are registered awaiting content. Of the six Fleet Coordination actions, Target Priority (a continuous, Scrap-derived damage bonus) and Escort Protection (a continuous, headcount-derived incoming-damage reduction, fully independent of Scrap) are mechanically live; Resource Recovery is live as Scrap's income itself; Emergency Repairs, Retreat Routes, and Salvage Collection (as its own loot system beyond Scrap) are registered. AF-021's dormant `stasis` status and AF-032's dormant `returning` projectile behaviour both gain their first producers via the Hunter's Harpoon Cannon. A dev-only spawn key ("3", DEV-guarded beside the debug overlay, alongside the Outlaws' "8", Machines' "9", Crystals' "7", Void's "6", Ancient Custodians' "5", and the Xenomorph Hive's "4") makes fleet encounters deterministically verifiable in the browser.
