# worldEvents — Galaxy Event Framework (AF-041, game layer)

**Purpose:** The world-simulation layer that makes the galaxy feel alive whether or not the player is present — Dynamic Event Generation across ten Event Categories, ten tracked World State values, Player Participation, and modular Event Chains.

**Responsibilities:** `EventCategory`/`WorldEventDef`/`GalaxyWorldEventDef` data shapes and the six genuinely-new per-category kind vocabularies (`worldEventData`); weighted-timer event generation (`WorldEventRuntime`).

**Dependencies:** none at the data/runtime layer — `WorldEventDef.kind` is a plain string, re-surfacing AF-038 (`galaxy`), AF-039 (`faction`), AF-040 (`economic`), and AF-017/036 (`environmental`) category kinds by value, not by type import, exactly mirroring how those kinds already cross the `EnvironmentalEventTriggered` bus fact as plain strings. The composition root applies World State deltas through AF-026's `MetaProgression.recordStat`, clamped by AF-038's `GalaxyRuntime.clampedDelta` (imported there, not here).

**Data structures:** `WorldEventDef`, `GalaxyWorldEventDef`, `EventChainRef` (a plain content-id reference, never a second mission/research/lore engine).

**Extension points:** new events/categories/World State keys are data; `WorldEventRuntime` is deliberately kept pure — World State is **not** a new persistence layer. The composition root reads/writes namespaced statistics (`worldState:<key>`), the exact pattern AF-038/039/040 already established for Sector Stability, Reputation, and Credits, now at the whole-galaxy layer.

**Known limitations:** of the ten World State values, only the six a sandbox event actually nudges (`threatLevel`, `resourceAvailability`, `factionActivity`, `ancientActivity`, `sectorStability`, `tradeNetworks`, `scientificProgress`, `civilianPopulation`, `explorationProgress` — nine of ten; `voidCorruption` has no sandbox producer yet) are mechanically live; the tenth is registered vocabulary awaiting content. Event Chains (`chainsInto`) are demonstrated as real data references on four of the ten sandbox events, but the runtime never auto-executes a chain — actually launching the referenced mission/research/lore content on player response is wired at the composition root for the two kinds with a natural existing hook today (`researchOpportunity` → `researchTree.addPoints`, and the "galaxy remembers" discovery via `meta.discover`); `missionChain`/`bossEncounter`/`factionCampaign`/`newBiome`/`hiddenCivilisation` remain registered, no consumer yet. World Evolution ("nothing important is forgotten") reuses AF-026's existing collections/statistics wholesale — a responded-to event is recorded via `meta.discover("lore", event.id)`, zero new persistence. The Notification System has two producers, both zero new UI: the in-run HUD flash reuses the existing toast list (`lootNotices`, already used by AF-037/038's event flashes) for events that fire mid-expedition, and — since the spec calls out "Galaxy Command displays" by name, and `lootNotices` only renders during Gameplay — the Galaxy Command screen's subtitle gains one more summary line for the last fired World Event, the exact pattern AF-038/039/040 already established there for their own Galaxy/Faction/Economy summaries.
