# achievements — Achievement and Collection Framework (AF-042, game layer)

**Purpose:** Permanent records of mastery (Achievements) and discovery (Collections), celebrating exploration and skill without a new grind loop.

**Responsibilities:** `AchievementDef`/`AchievementCriteria`/`DiscoveryLogEntry` data shapes and the sandbox roster (`achievementData`); pure completion checking against already-public `MetaProgression` state (`AchievementRuntime`); the one genuinely new persisted surface — Resources/Ancient Artefacts collections and the capped Discovery Log (`CollectionLedger`).

**Dependencies:** `game/meta` (`CollectionCategory`/`MasteryReward` — Prestige Rewards reuse AF-026's existing `CosmeticRewardKind` wholesale, zero new reward kinds). Reads `MetaProgression.stat()`/`snapshot.collectionCounts` (both already public) rather than editing the locked class.

**Data structures:** `AchievementDef`, `AchievementCriteria` (statThreshold | collectionCount — two ways to define Completion Criteria, both reads of existing public state), `DiscoveryLogEntry`, `CollectionLedgerSaveData`.

**Extension points:** new achievements are data; `AchievementRuntime.checkCompletions()` is a pure function of an `AchievementProgressReader` (an interface `MetaProgression` already satisfies structurally) — no dependency injection framework, just a small structural interface. Completion itself is recorded through AF-026's existing `meta.discover("achievements", id)`, the exact bucket its own Challenge engine's `grantReward` already writes into — zero new completion-persistence.

**Known limitations:** ten of the fifteen Collections categories the spec names are AF-026's existing `CollectionCategory` values, read directly; Elite Variants is already a live AF-034 producer under the existing `"enemies"` bucket (via `codexId`); Blueprints is AF-025's existing blueprint `Set` (`CraftingSystem.knowsBlueprint`), read as its own source rather than funnelled through `meta.discover`; Galaxy Discoveries is a derived view (intersecting AF-038's known point-of-interest ids against the player's discovered `"lore"`/`"biomes"` sets) rather than new storage. Resources and Ancient Artefacts are the two categories with no existing bucket, tracked by `CollectionLedger` — wired today at a handful of real call sites (buying/gaining a resource; discovering an Ancient Vault point of interest), not yet at every possible source. The Discovery Log records context at the same handful of call sites; extending it to every existing `meta.discover` call site across the codebase is content debt, not a design gap. Challenge Cadence (Daily/Weekly) is registered vocabulary with no clock-based reset mechanic — the spec itself hedges both as "(optional)," and no time-boxed reset system exists elsewhere in this offline-first project to hook into safely yet.
