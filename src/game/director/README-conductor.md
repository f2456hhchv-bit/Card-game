# conductor — Director Conductor (AF-056, game layer, inside `director/`)

**Purpose:** The pacing layer OVER AF-017's locked EnemyDirector — never a replacement. The Director keeps deciding WHAT to spawn and what it costs; the Conductor shapes WHEN it lands: reactive Recovery Windows open after elite battles, boss phases, major events, large waves, and resource discoveries, and while one is open, ordinary directives wait in a fair, capped Spawn Queue. Window length adapts to player struggle (recent damage taken + current hull, both live Adaptive Response inputs) — a dominating player gets barely a pause, a struggling one gets the full breath — hard-capped so recovery never feels excessive. "Adaptation adjusts pacing, not hidden difficulty" is structural: nothing in this layer can touch an enemy stat, a threat budget, or the phase engine.

**Responsibilities:** Responsibility/encounter-type/pressure/trigger/adaptive-input/mix-kind vocabulary, the total `WaveType → EncounterType` mapping (formalising AF-046 → AF-055's faction routings as the encounter catalogue), the pure `pressureFor(phase, windowOpen)` label, and conductor tuning (`conductorData`); the window/cooldown clocks, the struggle accumulator, the FIFO Spawn Queue with overflow-flush, and the five trigger entry points (`DirectorConductor`).

**Dependencies:** `director/directorTuning` (type-only: `DirectorPhase`, `WaveType`). The runtime itself is generic over the directive type — it never needs to understand what it queues. `EnemyDirector.ts` and `directorTuning.ts` remain **byte-for-byte unmodified**.

**Data structures:** `DirectorConductor<TDirective>`, `ConductorSnapshot`, `CONDUCTOR_TUNING`, `WAVE_TYPE_TO_ENCOUNTER_TYPE`.

**Extension points:** new recovery triggers are new `RECOVERY_TRIGGERS` entries plus one `openRecoveryWindow` call site; new adaptive inputs attach alongside `recordPlayerDamaged` (five of seven registered: averageKillSpeed, buildStrength, movementEfficiency, missionTime, resourceEconomy); new encounter types extend `ENCOUNTER_TYPES_AF056` and the mapping; per-difficulty pacing presets are `CONDUCTOR_TUNING` clones (the same per-run-clone pattern AF-037 uses for `eliteSquadSize`).

**Known limitations:** of the six Faction Mixing kinds, single-faction is every AF-046 → AF-055 entrance and dual-faction moments emerge mechanically when the queue flushes two different faction directives in one tick — the other four are registered. Boss directives (`MiniBossWave`/`BossWave`) bypass the gate entirely: boss timing belongs to AF-017/035. Deferred directives spawn relative to the player's position at flush time (the fairness distance is re-derived by `executeWave`, so a queued wave can never land inside vision). The queue caps at `maxQueuedDirectives`; overflow flushes the oldest immediately — pressure is deferred, never deleted, so soft-locking the Director by hiding in a recovery window is impossible. Windows never chain (cooldown-gated), so stacking triggers cannot produce excessive recovery.
