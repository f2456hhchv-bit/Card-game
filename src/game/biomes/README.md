# biomes — Biome Framework (AF-036, game layer)

**Purpose:** A biome is a gameplay experience, not a background — movement, combat, resources, enemies, and hazards all shift together. Almost every mechanism here was already reserved by an earlier module, waiting for a producer.

**Responsibilities:** Data shapes for core biome/condition/hazard/event/weather/interaction vocabulary and `BiomeDef` (`biomeData`); weather rotation, hazard-zone ticking, weighted Biome Event triggering, and pass-through accessors for resource weights / enemy buff / hazard immunities / threat modifier (`BiomeRuntime`).

**Dependencies:** `game/loot` (`LootCategory` — Resource Distribution feeds AF-023's existing `DropContext.smartLoot.categoryWeights` hook directly; nothing to build, it was reserved and unused). `game/bosses` (`HazardZoneDef`/`stepHazardZone` — a biome hazard IS AF-035's hazard-zone shape; imported cross-module rather than duplicated, since moving that file would touch a locked module's documented path). `game/equipment` (`EquipmentBonus` — a biome's enemy buff is the same shape every passive/ability bonus already uses). `game/combat` (`StatusKind` — hazard immunities reuse `StatusEngine.setImmunity` directly). `game/meta` (`CollectionCategory` — interactable discoveries reuse the already-registered `"biomes"`/`"lore"` categories).

**Data structures:** `BiomeDef`, `WeatherDef` (a `MovementModifier` "force" producer — AF-020 reserved that kind for "gravity, wind, currents" and this is the first real wind), `BiomeEventDef`, `InteractableDef`, `BiomeSnapshot`.

**Extension points:** new biomes are data; Biome Events extend AF-017's existing `EnvironmentalEventTriggered` bus event (typed as a plain `string`, so new event names need no schema change) rather than a second event channel — five of the ten event kinds (Solar Flare, Crystal Bloom, Void Breach, Machine Activation, Ancient Vault) are biome-flavoured names for AF-017's existing `EnvironmentalEventType` set; the other five (Distress Signal, Lost Expedition, Wandering Merchant, Prototype Wreckage, Faction Conflict) are genuinely new since AF-017 never modeled them. Interactables are schema-complete for all seven `InteractionKind`s; only `activateAncientDevice` (lore discovery) and `harvestResource` (bonus loot) are mechanically live — the rest (Destroy Obstacle, Open Hidden Area, Trigger Event, Disable Hazard, Unlock Secret) await their own consuming systems (arena obstacle destruction, hidden-area unlocking), the same "registered, no consumer yet" pattern established repeatedly.

**Known limitations:** biome visuals (palette, lighting, particles, skybox) build from AF-002/AF-004/AF-007/AF-008 at the content/visual module; only one sandbox biome (Crystal Fields) governs a live run today, its `id` written into the already-existing `RunSessionRecord.biomeId` field and its `threatModifier` feeding AF-017's already-existing `ThreatInputs.biomeModifier` — no Director change.
